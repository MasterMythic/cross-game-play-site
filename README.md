# Cross Game Play — investor site

Static, dependency-free investor website for Cross Game Play: vision, the granted patent (US 12,420,199 B2), the filed portfolio, the market, and why IP is the last moat in an AI world.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8765
```

Then visit http://127.0.0.1:8765.

## Files

- `index.html`: content and structure
- `styles.css`: design system, layout, responsive and reduced-motion rules
- `main.js`: particle avatar hero, scroll-driven diagrams, portfolio ledger, AI provenance demo

Fonts load from Google Fonts. Everything else is self-contained.
